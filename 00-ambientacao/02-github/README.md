# 02 – Primeiros passos com GitHub

O GitHub é uma plataforma para hospedar e organizar projetos e arquivos. Na disciplina, será utilizado para consultar materiais e trabalhar com repositórios de atividades.

## 1. Criar sua conta

Se ainda não possui uma conta, acesse [github.com/signup](https://github.com/signup). Utilize um endereço de e-mail que você consiga acessar e conclua a confirmação solicitada pelo GitHub.

Escolha um nome de usuário (username) que seja fácil de identificar e compartilhar com o professor.

## 2. Identificar seu perfil

Seu perfil estará disponível em um endereço semelhante a:

`https://github.com/seu-username`

O username é diferente do nome de exibição do perfil. É o identificador que será utilizado no cadastro da turma.

## 3. Conhecer um repositório

Um repositório (repository) é um espaço para armazenar arquivos de um projeto. Neste curso, os repositórios poderão conter:

- materiais e exemplos;
- enunciados de atividades;
- arquivos de código Python;
- instruções e documentação.

## 4. O que é um commit?

Um commit registra um conjunto de alterações feitas nos arquivos de um repositório. Pense nele como um registro identificado de uma etapa do trabalho.

Ao trabalhar em uma atividade, você poderá salvar suas alterações por meio de commits.

## 5. Cuidados com a conta

- Nunca compartilhe sua senha.
- Nunca publique tokens de acesso.
- Ative recursos de segurança oferecidos pelo GitHub.
- Confira se está utilizando a conta correta antes de trabalhar em uma atividade.
