# 04 – Instalação e configuração do Visual Studio Code

O Visual Studio Code (VS Code) será o editor de código padrão da disciplina. Ele permite criar e organizar arquivos, editar programas e executar Python por meio de um terminal integrado.

## 1. Baixar e instalar

Acesse o site oficial:

[https://code.visualstudio.com/](https://code.visualstudio.com/)

Baixe a versão adequada ao seu sistema operacional e siga as instruções de instalação.

## 2. Instalar a extensão Python

1. Abra o VS Code.
2. Selecione o ícone **Extensions** na barra lateral (ou use `Ctrl+Shift+X` no Windows/Linux e `Cmd+Shift+X` no macOS).
3. Pesquise por **Python**.
4. Instale a extensão **Python**, publicada pela Microsoft.
5. Se solicitado, permita a instalação de componentes recomendados.

A extensão auxilia na edição, execução e depuração de programas Python. Ela não substitui a instalação do interpretador Python.

## 3. Abrir uma pasta de trabalho

1. Crie uma pasta no computador chamada `algoritmos-programacao`.
2. No VS Code, escolha **File → Open Folder**.
3. Selecione a pasta criada.
4. Confirme a abertura da pasta.

Organizar os arquivos em uma pasta facilita localizar os programas e manter os materiais da disciplina separados de outros projetos.

## 4. Selecionar o interpretador Python

1. Abra a paleta de comandos: `Ctrl+Shift+P` (Windows/Linux) ou `Cmd+Shift+P` (macOS).
2. Digite `Python: Select Interpreter`.
3. Selecione a instalação do Python 3 que você instalou.
4. Confira se o interpretador selecionado aparece na barra de status ou nas opções de execução.

Se nenhum interpretador aparecer, confira a instalação do Python e reinicie o VS Code.

## 5. Abrir o terminal integrado

No menu, escolha **Terminal → New Terminal**. O terminal será aberto na parte inferior da janela.

Você poderá utilizá-lo para executar programas e verificar mensagens de erro.
