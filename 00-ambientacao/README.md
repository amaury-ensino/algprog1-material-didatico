# Unidade 00 – Ambientação e ferramentas

Bem-vindo(a) à disciplina **Algoritmos e Programação I**!

Nesta unidade, você irá preparar o ambiente que será utilizado durante as aulas e conhecer as ferramentas de apoio à aprendizagem.

## Objetivos

Ao concluir esta unidade, você deverá ser capaz de:

- acessar os materiais da disciplina no GitHub;
- compreender o que são repositórios e commits;
- instalar o Python e o Visual Studio Code (VS Code);
- configurar o VS Code para executar programas Python;
- criar, executar e modificar seu primeiro programa;
- compreender como as atividades serão disponibilizadas e entregues pelo Classroom 50.

## Percurso da unidade

1. [Apresentação da disciplina](01-apresentacao/README.md)
2. [Primeiros passos com GitHub](02-github/README.md)
3. [Instalação do Python](03-python/README.md)
4. [Instalação e configuração do VS Code](04-vscode/README.md)
5. [Seu primeiro programa](05-primeiro-programa/README.md)

## O que você precisará

- um computador com Windows, macOS ou Linux;
- acesso à internet;
- uma conta pessoal no GitHub;
- Python 3 instalado;
- Visual Studio Code instalado.

> **Importante:** não compartilhe sua senha, token de acesso ou códigos de autenticação. A disciplina nunca solicitará esses dados.

## Atividade de conclusão

Ao final, você deverá ter executado o programa `hello.py` e conseguido modificar a mensagem apresentada na tela.
