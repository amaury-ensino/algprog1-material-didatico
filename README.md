# Algoritmos e Programação I

Repositório oficial de materiais didáticos da disciplina **Algoritmos e Programação I**, destinada aos estudantes do curso de graduação.

## Sobre a disciplina

A disciplina tem como objetivo desenvolver o pensamento computacional e os fundamentos da programação de computadores, utilizando a linguagem Python.

Ao longo da disciplina, serão explorados conceitos de lógica de programação, representação de algoritmos, estruturas de controle, estruturas de dados básicas e modularização de programas.

## Objetivos de aprendizagem

- Compreender os fundamentos da lógica de programação.
- Desenvolver algoritmos para resolver problemas computacionais.
- Implementar soluções utilizando Python.
- Aplicar estruturas de controle e estruturas de dados básicas.
- Desenvolver habilidades de análise, implementação, teste e depuração de programas.

## Metodologia de aprendizagem

As atividades poderão envolver leitura e análise de programas, execução de códigos, investigação de soluções, modificação de algoritmos e desenvolvimento de programas.

Será utilizada, entre outras estratégias, a abordagem PRIMM:

1. Predict – Prever
2. Run – Executar
3. Investigate – Investigar
4. Modify – Modificar
5. Make – Criar
